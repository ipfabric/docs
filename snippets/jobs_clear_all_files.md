!!! warning "Clearing Jobs Does Not Delete Generated Files"

    The **Clear all** button in the **Jobs** list removes only the job entries
    (notifications and history) from the GUI. The files generated by those jobs,
    such as downloaded snapshots and techsupport files, remain stored on the
    appliance in the `/home/autoboss/files` directory.

    These files are removed only when System Maintenance runs (**Settings -->
    System --> Backup & Maintenance --> Schedule System Maintenance**) and
    purges the files that no longer belong to any job. Until then, they continue
    to occupy disk space, which can eventually lead to `Not enough disk space`
    errors that block new discoveries, snapshot processing, or maintenance
    tasks.
