### Improvements

#### Vendor Support

**Avocent ACS**

IP Fabric extends Avocent ACS discovery. Coverage now includes:

* **Telnet** – Avocent ACS can now be discovered over Telnet as well as SSH,
* **ARP table** – ARP entries are now collected,
* **Routing table** – IPv4 and IPv6 routes are now collected,
* **LLDP neighbors** – LLDP neighbors are now collected,
* **Power supplies** – the state of each power supply (on/off) is now
  collected,
* **Interfaces** – L2 and L3 interfaces (IPv4 and IPv6) are now collected,
* **SNMP** – trap hosts, communities and SNMPv3 users are now collected,
* **AAA** – RADIUS, TACACS+, LDAP/AD, Kerberos and DSView servers, local accounts, and the authentication method of each serial (console) port are now collected,
* **Serial ports** – serial ports are now collected, with their status, speed

See [Feature Matrix](https://matrix.ipfabric.io/) for details.

!!! warning "Disabled by Default"
    To enable it, set the `ENABLE_DISCOVERY_DEVICES_AVOCENT` feature flag. See [Feature Flags](../../System_Administration/Command_Line_Interface/Feature_Flags.md#avocent-acs-discovery) for details.



### API changes

#### Technology tables changes

- `/technology/routing/ospf/neighbors` (API endpoint `/api/tables/routing/protocols/ospf/neighbors`)
  - Unused `neiArea` column was removed.
- `/technology/routing/ospf-v3/neighbors` (API endpoint `/api/tables/routing/protocols/ospf-v3/neighbors`)
  - Unused `neiArea` column was removed.
