### Improvements

- **Azure**
  - IP Fabric now collects all Key Vault certificates, including those not assigned to any resource, requiring a new permission.

  !!! warning "New Azure Permissions Required"

      Add `Microsoft.KeyVault/vaults/read` to your [Azure custom role](../../IP_Fabric_Settings/Discovery_and_Snapshots/Discovery_Settings/Vendors_API/azure.md#role-definitions-for-ip-fabric) to enable this feature.

### API changes

#### Technology tables changes

- `/technology/routing/ospf/neighbors` (API endpoint `/api/tables/routing/protocols/ospf/neighbors`)
  - Unused `neiArea` column was removed.
- `/technology/routing/ospf-v3/neighbors` (API endpoint `/api/tables/routing/protocols/ospf-v3/neighbors`)
  - Unused `neiArea` column was removed.
