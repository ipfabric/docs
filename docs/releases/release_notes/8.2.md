#### Vendor Support

**GCP**

**Operating System and Image** -- IP Fabric now collects the operating system
type and image of GCP virtual machines. It resolves both from the
boot disk of the virtual machine and its source image. These fields were previously
empty for GCP.

!!! warning "New GCP Permissions Required"

    Add the `compute.disks.list` and `compute.images.get` permissions
    to your [GCP IAM role](../../IP_Fabric_Settings/Discovery_and_Snapshots/Discovery_Settings/Vendors_API/GCP_Google_Cloud_Platform.md#how-to-create-a-custom-role) to enable this feature.
